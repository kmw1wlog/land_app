# 국토교통 제출서용 문구

## 현재 상태 문구

국토교통 실거래 데이터와 한국부동산원(KREB) 공식 실데이터를 실제로 융합하여 단지·지역별 주거 안정성 점수를 산출한다. HUG·교통 접근성은 현재 시드 스냅샷으로 보조 반영하며, 실데이터로 단정하지 않는다.

## AI 활용 문구

HomePath는 Time-Series Transformer, TurboQuant-inspired RAG, Qwen 설명봇을 결합해 공공데이터 근거 기반 주거 구매력·갈아타기 리스크 설명을 제공한다.
