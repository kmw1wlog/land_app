# 모두의 창업 제출 영상 녹화 가이드

업데이트: 2026-05-14

## 목적

45초 안에 앱의 핵심을 보여준다.

> **내 집 팔고 어디까지 갈 수 있을까?  
> 실거래로 그리는 부동산 사다리 앱.**

## 준비

1. 개발 서버 실행

```bash
npm run dev
```

2. 데모 페이지 접속

```text
http://localhost:3000/demo-submission
```

3. 권장 녹화 설정

```text
해상도: 1920x1080
비율: 16:9
길이: 45초
음성 톤: 차분한 설명형
```

## 녹화 순서

### 0~4초. 타이틀

화면:

```text
내 집 팔고 어디까지 갈 수 있을까?
```

내레이션:

> 부동산 앱은 많지만, 내 상황에서 어디까지 갈 수 있는지 알려주는 앱은 부족합니다.

### 4~9초. 문제

화면:

```text
실거래가
거래량
매물
단지정보
그래서 나는 어디까지 갈 수 있지?
```

내레이션:

> 실거래가도 보고, 거래량도 보고, 단지도 보지만 결국 질문은 하나입니다.

### 9~15초. 내 상황 입력

클릭: `다음`

화면:

```text
현재 집 8억
월소득 650만
보유현금 1.2억
관심지역 수성구/성동구
```

내레이션:

> 현재 집, 월급, 현금, 관심지역을 입력하면…

### 15~23초. 사다리 요약

클릭: `다음`

화면:

```text
현재 구매력 8.2억
매도 시 11.6억
5년 뒤 13.1억
1.5배 목표 12억
```

내레이션:

> 지금 가능한 가격대, 집을 팔면 가능한 가격대, 5년 뒤 가능한 가격대를 계산합니다.

### 23~30초. 실거래 후보 카드

클릭: `다음`

화면:

```text
1.5배 후보
최근 실거래 기준가 11.9억
거래 집중도 3.1배
전고점 대비 -14%
DSR 38%
```

내레이션:

> 그리고 공공 실거래 데이터를 바탕으로 최근 거래가 활발한 단지와 면적대를 보여줍니다.

### 30~36초. 같은 돈 비교

클릭: `다음`

화면:

```text
A단지 / B단지 / C단지
기준가
전고점 대비
거래량
전세가율
월부담
```

내레이션:

> 한 단지에 꽂히지 않도록, 같은 가격대의 다른 후보도 자동으로 비교합니다.

### 36~41초. 커뮤니티

클릭: `다음`

화면:

```text
보유자
실거주자
매수대기자
A단지 84㎡, 갈아타기 후보로 어떤가요?
```

내레이션:

> 데이터만으로 부족한 맥락은 단지별 커뮤니티에서 확인합니다.

### 41~45초. 마무리

클릭: `다음`

화면:

```text
부동산을 보는 앱이 아니라,
내 미래를 그리는 앱.
```

내레이션:

> 부동산을 보는 앱이 아니라, 내 미래를 그리는 앱.

자막:

```text
실거래로 그리는 부동산 사다리 앱
```

## 조작법

- `다음` 버튼 클릭
- `Space` 또는 `Enter`: 다음 단계
- `←` / `→`: 이전/다음 단계

## 자동 녹화

개발 서버가 `http://127.0.0.1:3000`에서 실행 중일 때:

```bash
npm run record:demo
```

출력:

```text
public/demo/modoo-startup-demo.webm
```

서버 주소가 다르면:

```bash
DEMO_BASE_URL=http://127.0.0.1:3010 npm run record:demo
```

## OpenAI TTS 내레이션 합성

무음 녹화본에 자연스러운 한국어 내레이션을 넣고, 배경음악 없는 버전과 있는 버전을 함께 만든다.

준비:

```bash
export OPENAI_API_KEY=...
```

또는 `.env.local`에 다음 값을 넣는다.

```env
OPENAI_API_KEY=...
```

실행:

```bash
npm run create:demo-voiceover
```

출력:

```text
public/demo/modoo-startup-narration.txt
public/demo/modoo-startup-narration.mp3
public/demo/modoo-startup-demo-voiceover.mp4
public/demo/modoo-startup-demo-voiceover-bgm.mp4
```

배경음악 버전은 외부 음원 저작권 이슈를 피하기 위해 ffmpeg로 생성한 아주 낮은 볼륨의 단순 신스 톤을 사용한다. 제출 전에는 반드시 직접 들어보고 음량을 확인한다.

## 제출용 이미지 캡처

캡처 페이지:

```text
http://localhost:3000/demo-captures
```

포함 섹션:

1. 문제-해결 요약
2. 기존 앱 vs 우리 앱
3. MVP 핵심 화면 4종
4. 데이터/기술 구조도
5. 사업화 로드맵

각 섹션은 16:9 비율로 캡처하기 쉽게 구성되어 있다.
