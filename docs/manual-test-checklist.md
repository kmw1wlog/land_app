# Manual Test Checklist

1. `/onboarding`에서 월급, 현금, 월 저축액, 목표 집 가격, 목표 시점 입력
2. `/my-home`에서 현재 집 주소 입력
3. 주소 정규화 실행
4. 실거래 수집 실행
5. 현재가 추정 실행
6. 내 집 마인드맵 노드별 숫자 badge 확인
7. `/feed`에서 카드의 현재 가능, 매도 시 가능, 3년/5년/10년 가능성 확인
8. `/goal-path`에서 저축/매도/전세전환/월세전환 루트 확인
9. `/portfolio`에서 가상 후보 저장 후 목표 월세/목표 집 지표 확인
10. `/community`에서 글/댓글/좋아요/신고 동작 확인
11. 카드 상담 버튼에서 개인정보 전달 동의 모달 확인
12. 동의 후 lead 생성 확인
13. `/broker`에서 중개사 등록, 인증, 매물 등록, lead 목록 확인
14. `/api/public-data/health?probe=true`에서 실제 API probe 결과 확인

모든 계산 결과는 “참고용 추정치이며 실제 시세·세금·대출한도와 다를 수 있습니다.” 문구 또는 동등한 참고용 안내가 보여야 한다.
