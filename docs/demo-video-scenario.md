# HomePath 45~60초 시연 영상 시나리오

## 산출물

- MP4: `public/demo/homepath-molit-demo-60s.mp4`
- WebM: `public/demo/homepath-molit-demo-60s.webm`
- 렌더링 스크립트: `npm run demo:video`
- 기준 URL: `http://127.0.0.1:3002/demo-submission` 또는 `DEMO_BASE_URL=https://land-app-mu.vercel.app npm run demo:video`

## 영상 조건

- 길이: 60초
- 화면비: 16:9
- 해상도: 1920x1080
- 스타일: 공공기관 제출용 시제품 시연
- 배경음악: 저음량 합성 패드 BGM
- 개인정보/API key/개발자 콘솔 노출 없음

## 장면 구성

| 구간 | 화면 | 핵심 자막 | 내레이션 요지 |
| --- | --- | --- | --- |
| 0~5초 | 문제 제기 | 정보는 많은데, 내 조건의 답은 부족합니다. | 실거래가와 매물은 많지만 내 월급과 현금 기준 판단은 직접 계산해야 했습니다. |
| 5~12초 | 온보딩 입력 | 소득·현금·현재 주거 기준점 입력 | HomePath는 소득, 현금, 현재 주거 기준점, 관심지역을 입력받습니다. |
| 12~20초 | 구매력 계산 | 현재·정리 후·5년 뒤 구매력 계산 | 입력값을 바탕으로 현재 구매력, 정리 후 구매력, 5년 뒤 구매력을 계산합니다. |
| 20~30초 | 후보 카드 및 융합 안정성 | MOLIT real + KREB real 융합 안정성 점수 | 국토교통부 실거래 데이터와 한국부동산원 지역지수를 융합해 주거 안정성 점수를 산출합니다. |
| 30~42초 | AI 설명봇 | Transformer + TurboQuant-RAG + Qwen 설명봇 | Transformer 안정성 신호와 RAG 근거를 Qwen이 후보 이유와 주의점으로 설명합니다. |
| 42~52초 | 같은 예산 비교 | 같은 예산 후보 비교 | 같은 예산 후보를 기준가, 월부담, 전세가율, 안정성 신호로 비교합니다. |
| 52~60초 | 마무리 | 매수 추천이 아닌 공공데이터 기반 의사결정 보조 | HomePath는 매수 추천이나 수익 보장이 아니라 무리한 주거 선택을 줄이는 보조 서비스입니다. |

## 금지 표현

- 오를 집 추천
- 매수 추천
- 수익 보장
- 대출 승인 가능
- 투자 타이밍 확정

## 확인 포인트

- 온보딩 → 구매력 계산 → 후보 카드 → 융합 안정성 점수 → AI 설명봇 → 같은 예산 비교 흐름이 보인다.
- `MOLIT real + KREB real` 문구가 후보/융합 안정성 장면에 보인다.
- `fusion_data`, `kreb_market_index`, `model_artifact`, `safety_policy` 근거가 AI 설명 장면에 보인다.
- 마지막 장면에 “매수 추천·수익 보장·대출 승인 보장 아님” 안전 문구가 보인다.
