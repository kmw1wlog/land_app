# 홈패스(HomePath) 국토교통 데이터 활용 경진대회 제출 전환안

## 1. 변경 목적

기존 앱은 `내 집 팔고 어디까지 갈 수 있을까?`라는 부동산 사다리 MVP로 설계되어 있었다. 국토교통부 제출용 버전에서는 정권·정책 환경, 청년 주거 이슈, 공공성, 심사 기준을 고려해 아래 제목으로 재정의한다.

> **청년·사회초년생을 위한 공공데이터 기반 주거 구매력·갈아타기 리스크 진단 서비스, 홈패스**

이 변경은 제품의 핵심을 버리는 것이 아니라, 기존 갈아타기 사다리 기능을 더 공공성과 정책 적합성이 높은 표현으로 재포장하는 것이다.

## 2. 새 포지션

### 기존 포지션

- 현재 집을 팔면 어디까지 갈 수 있는지 계산하는 부동산 사다리 앱
- 실거래 기반 갈아타기 후보 피드
- 같은 돈 비교와 단지 커뮤니티

### 국토교통 제출용 포지션

- 청년·사회초년생·1주택자의 주거 구매력과 주거 이동 리스크를 진단하는 공공데이터 기반 서비스
- 매물앱이 아니라 의사결정 보조 서비스
- 공공 실거래 데이터와 AI 시계열 분석을 결합한 설명 가능한 후보 추천
- 무리한 선택을 줄이고 정보 비대칭을 완화하는 주거 의사결정 인프라

## 3. 앱 내부 문구 수정 방향

### 브랜드명

- `홈패스(HomePath)`

### 메인 카피

- 지금 내 조건으로 어디까지 가능할까?
- 공공데이터로 진단하는 주거 구매력과 갈아타기 리스크
- 막연한 주거 고민을 설명 가능한 경로로

### 금지하거나 축소할 표현

- 오를 집 추천
- 매수 추천
- 수익 보장
- 불로소득 설계
- 고수익 투자
- 현재 매물 있음 단정

### 사용할 표현

- 주거 구매력
- 미래 구매력
- 갈아타기 리스크
- 주거 이동 경로
- 실거래 기반 분석 후보
- 참고용 추정
- 의사결정 보조
- 현재 매물은 외부 사이트에서 확인

## 4. 화면별 수정안

### 4.1 온보딩

기존 `목표: 갈아타기` 중심에서 아래 선택지를 추가한다.

- 첫 주거 구매 준비
- 전세/월세에서 자가 전환
- 현재 집 정리 후 이동
- 3년 뒤 구매력 확인
- 5년 뒤 주거 목표 설정

입력값은 유지한다.

- 월소득
- 보유현금
- 월저축액
- 현재 주거비
- 관심지역
- 현재 집 또는 현재 전세/월세 기준점

### 4.2 Feed

기존 실거래 기반 단지 피드는 유지하되 카드 라벨을 바꾼다.

- 구매력 적합 후보
- 조건부 가능 후보
- 미래 접근 가능 후보
- 거래 집중 후보
- 전세가율 안정 후보
- 리스크 확인 필요 후보

카드 하단 문구:

> 공공 실거래가 기반 분석 후보입니다. 실제 매물은 외부 사이트에서 확인하세요.

### 4.3 My Home

현재 집 보유자만 대상으로 보이지 않도록 `내 주거 기준점`으로 확장한다.

- 현재 전세 보증금
- 현재 월세 주거비
- 현재 보유 주택
- 현재 집 추정가

### 4.4 Goal Path

`내 사다리`를 `주거 경로`로 바꾸되, 내부 계산은 유지한다.

- 현재 구매력
- 정리 후 구매력
- 3년 뒤 구매력
- 5년 뒤 구매력
- 장기 목표 후보

### 4.5 Compare

기존 같은 돈 비교는 유지한다.

대회용 표현:

> 같은 예산이면 어디가 더 안전한가?

비교 항목:

- 최근 실거래 기준가
- 전고점 대비
- 거래량
- 전세가율
- 월부담
- DSR/LTV
- 유동성
- 데이터 신뢰도

### 4.6 Community

기존 종토방 표현을 줄이고, `데이터 기반 커뮤니티`로 표현한다.

- 실거주자 의견
- 지역 경험자 의견
- 청년 매수대기자 질문
- 데이터 기반 질문 템플릿

## 5. AI 활용 강화안

통합공고 기준 AI 평가에서 단순 GPT 붙이기나 단순 인기순 추천은 약하다. 따라서 홈패스는 아래 3층 구조로 설명한다.

### 5.1 Time-Series Transformer

공공 실거래 데이터를 월별 feature로 변환해 단지·면적대별 미래 신호를 학습한다.

입력 feature:

- median_price
- weighted_price
- trade_count
- rent_count
- jeonse_median
- jeonse_ratio
- drawdown_from_high
- transaction_heat
- reacceleration_score
- liquidity_score
- leader_score

출력:

- future recovery probability
- future transaction heat probability
- AI candidate score

### 5.2 Explainable Recommendation

AI 점수만 보여주지 않고, 추천 이유를 함께 보여준다.

예:

- 최근 90일 거래량이 증가했습니다.
- 전세가율이 유사 후보보다 높습니다.
- 현재 구매력으로는 부족하지만 5년 뒤 구매력 안에 들어옵니다.
- DSR/LTV가 경계값에 가까워 리스크 확인이 필요합니다.

### 5.3 LLM 활용

LLM은 판단을 대신하지 않는다. 공공데이터와 계산 결과를 사용자에게 이해 가능한 문장으로 바꾸는 역할을 한다.

- 같은 돈 비교 요약
- 주거 경로 요약
- 데이터 기반 커뮤니티 질문 템플릿 생성
- 결과 해석 보조

## 6. 국토교통 제출용 3장 기획서 구조

### 1페이지: 문제와 고객

제목:

> 청년·사회초년생은 주거 정보를 보지만, 자신의 구매력 답은 얻기 어렵다.

핵심 내용:

- 기존 부동산 앱은 정보와 매물 중심
- 청년·사회초년생은 월급·현금·주거비 기준 판단이 필요
- 1주택자는 현재 집 정리 후 이동 가능성이 필요
- 홈패스는 공공데이터로 개인별 주거 경로를 계산

### 2페이지: 서비스와 기술

제목:

> 공공 실거래 데이터와 AI로 주거 구매력·리스크를 진단한다.

핵심 내용:

- 실거래/전월세/건축물대장/법정동코드 활용
- 단지·면적대·층수대 시그널 생성
- Transformer 기반 미래 신호 분석
- 설명 가능한 추천 엔진
- 시제품 URL과 데모 화면

### 3페이지: 차별화와 성장성

제목:

> 매물앱이 아니라 주거 의사결정 보조 서비스다.

핵심 내용:

- 호갱노노/아실/네이버와 차별화
- 매물 크롤링 없음
- 청년·사회초년생 주거 계획 지원
- 관심단지 알림, 리포트, 상담 연결로 사업화
- 대구 수성구/서울 성동구 파일럿 후 확장

## 8. 남은 구현 과제

### 우선순위 높음

- 데모 화면의 제목과 문구를 홈패스 포지션으로 전체 수정
- `현재 집` 문구를 `현재 주거 기준점`으로 확장
- `/feed` 카드 문구에서 투자성보다 주거 구매력 진단을 강조
- AI 모델 학습 결과 예시 파일 생성
- 제출용 3장 PDF 또는 HWP 작성

### 우선순위 중간

- 청년·사회초년생 전용 온보딩 UX
- 주거비 부담률 계산
- 월세/전세에서 자가 전환 시나리오
- 교통 접근성/K-MaaS 데이터 연계 검토

### 우선순위 낮음

- 중개사 리드 기능 전면 노출
- 직영 매물 기능
- 매물 사진 기능

## 9. 심사 대응 문장

> 홈패스는 집을 추천하는 앱이 아니라, 공공 실거래 데이터와 사용자 입력값을 결합해 주거 구매력과 갈아타기 리스크를 설명하는 의사결정 보조 서비스입니다.

> AI는 단순 검색이 아니라 공공 실거래 시계열을 학습해 후보 단지의 미래 신호를 분석하고, 추천 이유를 설명하는 데 사용됩니다.

> 매물 크롤링 없이 공공데이터 기반 분석 후보를 만들고, 실제 매물 확인은 외부 링크로 연결해 저작권·허위매물 리스크를 줄입니다.
